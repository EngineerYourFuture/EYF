# 02 · MVP Scope

## ✅ In Scope (MVP)

| Area | Detail |
|------|--------|
| Auth | Public auth + Authority auth |
| RBAC | Roles: user, staff, admin |
| Plans | Entitlements: Free / Basic / Pro / Elite |
| DSA | Problem list / detail / editor / run / submit |
| Execution | Docker execution sandbox (hardened) |
| Visualizer | MVP — sorting algorithms + binary search |
| Recommendations | Engine v1 (rule-based) |
| Core Subjects | OS / DBMS / CN / OOP |
| Placement | Attempts + mock interview gating |
| Mentorship | Booking with monthly quotas |
| Resume | Builder + PDF export |
| Billing | Checkout, webhook, plan change flows |
| Operations | Analytics, support tickets, authority workflows |

---

## ❌ Out of Scope (Post-MVP)

| Feature | Reason |
|---------|--------|
| AI interview copilot | Complexity — post-MVP |
| Community forum | Post-MVP |
| Enterprise multi-tenant org features | Post-MVP |
| Full algorithm visualizer coverage | Partial MVP only (sorting + binary search) |
