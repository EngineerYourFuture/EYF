# 26 · Definition of Done

A feature is considered **Done** only when **all 5** of the following criteria are met.

---

## Checklist

| # | Criterion | Description |
|---|-----------|-------------|
| ✅ 1 | **Functional Acceptance** | Feature works as specified — all acceptance criteria pass |
| 🔒 2 | **Security Controls Validated** | Auth, ownership, entitlement, rate-limit checks in place and tested |
| 🤖 3 | **Automated Tests Pass** | Unit + integration tests green in CI |
| 📡 4 | **Monitoring & Audit Logging** | Metrics/alerts configured, audit log entries created where required |
| 🎨 5 | **UX States Complete** | Loading, empty, error, and success states all implemented |

---

> **A feature that meets only 4/5 criteria is NOT done.**
