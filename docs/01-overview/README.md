# 01 · Product Overview

## Problem Statement

Current users rely on fragmented tools (coding sites, notes apps, prep portals, resume tools), causing:
- Context switching
- Low retention
- Weak feedback loops
- Poor placement outcomes

**EYF solves this** with one connected workflow and clear progression paths.

---

## Product Description

EYF is a guided engineer growth platform that unifies:
- **Coding practice** — DSA problem set with execution sandbox
- **Concept revision** — Core subjects (OS, DBMS, CN, OOP)
- **Execution understanding** — Algorithm visualizer
- **Placement preparation** — Mock interviews, company prep, referrals
- **Resume readiness** — Structured resume builder with PDF export

---

## Core Loop

```
Pick Problem → Solve → Run → Submit → Visualize → Next Problem
```

The MVP must connect this loop to:
- Measurable progression (XP / streaks)
- Plan-based access control
- Secure monetization
