# 12 · Module-First Product Structure

> **Section 27 — Critical Update**
>
> EYF is a **module-based** engineer growth platform, not only a problem-solving app. After login, users must land on a unified Module Home and choose what to work on.

---

## The Five Primary Modules

| # | Module | Purpose |
|---|--------|---------|
| 1 | DSA Practice | Coding fluency, pattern recognition, interview confidence |
| 2 | Core Subjects | CS fundamentals (OS / DBMS / CN / OOP) |
| 3 | Placement Prep | Interview readiness — aptitude, coding rounds, mocks |
| 4 | Resume Builder | Job-ready resume with live preview + PDF export |
| 5 | Tech Skills | Practical stack readiness beyond DSA |
