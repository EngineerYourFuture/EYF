# 27.3 · Landing Page Requirements (`/`)

**Goal:** Convert visitors into registered users and clearly communicate multi-module value.

---

## Required Sections (in order)

| # | Section | Content |
|---|---------|---------|
| 1 | **Hero** | Headline + primary CTA "Get Started" + secondary CTA "Login" |
| 2 | **Value Proposition Strip** | Learn · Practice · Track · Apply · Get Hired |
| 3 | **Module Overview Cards** | All 5 modules displayed with purpose and CTA |
| 4 | **Plan Comparison Preview** | Free / Basic / Pro / Elite highlights |
| 5 | **Outcomes / Social Proof** | Stats, testimonials, or outcome examples |
| 6 | **FAQ** | Common questions answered |
| 7 | **Security / Trust Strip** | Secure billing, account protection, privacy |
| 8 | **Footer** | Policy / legal links |
| 9 | **Authority Login Link** | Link to `/authority/login` (discreet placement) |

---

## Mandatory CTAs

| CTA | Route / Action |
|-----|---------------|
| **Start Free** | → `/auth/register` |
| **View Plans** | → Plan comparison section or billing page |
| **Login** | → `/auth/login` |
| **Authority Login** | → `/authority/login` |

---

## Design Notes

- Hero CTA "Get Started" must be high-contrast and above the fold
- Module cards must reflect all 5 modules (not just DSA)
- Plan preview must clearly differentiate Pro vs Free to drive upgrade intent
- Security/trust strip reinforces payment safety for conversion
