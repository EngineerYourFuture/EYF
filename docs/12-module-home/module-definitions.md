# 27.6 · Module Definitions

Detailed specification for all five primary modules.

---

## A · DSA Practice

**Purpose:** Coding fluency, pattern recognition, interview coding confidence.

### Core Capabilities

| Capability | Detail |
|-----------|--------|
| Problem list | Filter / search / paginate problems |
| Run / Submit | Execute against sample + hidden test cases |
| Success insights | Post-solve recommendations |
| Visualizer | Pro / Elite only (sorting + binary search) |

### Success Metrics

| Metric | Description |
|--------|-------------|
| Attempts / day | Daily problem attempt count |
| Acceptance rate | % of submits that pass |
| Topic mastery trend | Mastery score per topic over time |

---

## B · Core Subjects

**Purpose:** Strengthen CS fundamentals (OS / DBMS / CN / OOP).

### Core Capabilities

| Capability | Detail |
|-----------|--------|
| Subject / topic browsing | Hierarchical subject → topic listing |
| Note / video access | Gated by plan level |
| Topic completion marking | User marks topics as done |
| Weak-topic mapping | Links weak topics to relevant DSA / Placement items |

### Success Metrics

| Metric | Description |
|--------|-------------|
| Topics completed / week | Weekly learning throughput |
| Revision frequency | How often user revisits topics |
| Weak-topic reduction | Reduction in flagged weak topics over time |

---

## C · Placement Prep

**Purpose:** Interview readiness via aptitude, coding rounds, and mock interviews.

### Core Capabilities

| Capability | Detail |
|-----------|--------|
| Aptitude attempt logging | Record aptitude test attempts |
| Coding attempt logs | Log coding round attempts |
| Mock interviews | Pro / Elite only |
| Interview question bank | Access gated by plan |

### Success Metrics

| Metric | Description |
|--------|-------------|
| Mock completion rate | % of scheduled mocks completed |
| Score trend | Score progression over mock attempts |
| Readiness index | Composite score of overall placement readiness |

---

## D · Resume Builder

**Purpose:** Create and maintain a job-ready resume inside EYF.

### Core Capabilities

| Capability | Detail |
|-----------|--------|
| Structured resume form | Sections: personal, experience, education, projects, skills |
| Live preview | Real-time render as user types |
| Template selection | Multiple layout templates |
| PDF export | Plan-gated — Pro / Elite only |

### Success Metrics

| Metric | Description |
|--------|-------------|
| Profile completeness score | % of resume fields filled |
| Export count | Number of PDFs exported |
| Update cadence | How frequently user updates resume |

---

## E · Tech Skills

**Purpose:** Track practical stack readiness beyond DSA (projects, tools, workflows).

### Core Capabilities

| Capability | Detail |
|-----------|--------|
| Skill roadmap / track view | Visual map of skill domains and levels |
| Progress by skill domain | Per-domain completion tracking |
| Milestone / checkpoint tracking | Checkpoints within each skill track |
| Recommended next skill tasks | Engine-driven next skill suggestion |

### Success Metrics

| Metric | Description |
|--------|-------------|
| Skill milestone completion | Milestones achieved per domain |
| Consistency score | Regularity of skill activity |
| Roadmap adherence | % of recommended path followed |
